
# 🦇 Batman Logo – 3D CAD Design

## 📌 Overview

This project is a **3D CAD model of the Batman logo** designed using **Onshape**. The design was created from scratch by developing the logo geometry as a 2D sketch and transforming it into a 3D model.

The project demonstrates fundamental **CAD modeling, sketching, geometric design, and 3D extrusion** techniques.

---

## 🎯 Objectives

* Design the Batman logo using Onshape.
* Practice creating accurate 2D sketches.
* Convert a 2D sketch into a 3D model.
* Apply CAD constraints and geometric techniques.
* Develop experience with 3D modeling and STL file export.

---

## 🛠️ Tools & Technologies

| Tool        | Purpose                    |
| ----------- | -------------------------- |
| **Onshape** | 3D CAD modeling and design |
| **STL**     | Exported 3D model format   |

---

## 🔨 Design Process

### 1. Create the Sketch

A new sketch was created in Onshape and the Batman logo was constructed using lines, curves, and geometric elements.

### 2. Build the Logo Geometry

The individual sections of the logo were shaped and adjusted to create the recognizable Batman silhouette.

### 3. Apply Dimensions & Constraints

Dimensions and geometric constraints were used to improve the accuracy and consistency of the design.

### 4. Create the 3D Model

The completed 2D sketch was converted into a 3D object using the **Extrude** feature.

### 5. Export the Model

After completing and checking the design, the model was exported as an **STL file**.

---

## 📐 Final Result

The final result is a **3D Batman logo model** created entirely in Onshape.

The model can be used as a demonstration of basic CAD modeling techniques and can also be prepared for **3D printing**.
